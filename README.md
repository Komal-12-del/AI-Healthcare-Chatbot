# 🩺 AI Healthcare Chatbot

An AI-powered healthcare chatbot built using Python, Flask, and
TF-IDF-based text similarity. The chatbot allows users to ask
common healthcare-related questions and provides relevant
responses based on its knowledge base.

## 🚀 Features

- Healthcare question-answer chatbot
- Natural language matching using TF-IDF
- Cosine similarity for finding relevant responses
- Greeting detection
- Simple and responsive web interface
- Flask backend API
- Real-time chat interaction

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- HTML
- CSS
- JavaScript
